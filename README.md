# 🏝️ 单词冒险岛

本地单机单词闯关游戏，双击 `index.html` 即可在浏览器中游玩（推荐 Chrome / Edge / Safari）。
无需联网、无需安装任何东西。

## 玩法

- 世界地图上有 **5 座岛屿**（1 个讲义单元 = 1 座岛）：🩺 健康岛、🌿 自然岛、🎭 社团岛、🔬 科学岛、💻 未来岛，每座岛上有 3~4 扇魔法门
- **岛屿解锁**：第 1 座岛直接开放；闯完一座岛的全部大门后，下一座岛**第二天**开放
- 岛内按顺序闯关，**没有每日上限**；已通关的门随时可重玩
- 点击一扇门会弹出行动菜单：
  - 🎯 **闯关答题**：每关约 8 题，题型随机轮换——看中文选英文 / 听单词选意思 / 拼写补全 / 短语配对 / 看英文选中文
  - 🔗 **连连看**：英文 ↔ 中文配对消消乐，每轮 6 对；全部完成后展示「词族树」🌳，把同一家族的单词（如 treat → treatment → treatable）放在一起记
  - ✍️ **默写训练营**：三档难度（L1 补全字母 / L2 字母块拼词 / L3 听音默写），每轮 8 词；答错的词自动加入「薄弱词」池，优先出题；连续 2 次全对可自动升级难度（可关闭）
- 答错的题会插回队列重练；按答错次数评星：0 错 ⭐⭐⭐ / ≤2 错 ⭐⭐ / 更多 ⭐
- ⏱️ **限时答题**：设置里可选每题 5 秒 / 10 秒（默认不限），超时算答错
- 🔁 **艾宾浩斯复习曲线**：通关后按 1 / 2 / 4 / 7 / 15 / 30 天的间隔提醒复习；到期时门上出现 🔁 徽章，📊 总览里也会标红「今日需复习」
- 💠 **精灵碎片**：闯完一座岛的全部大门获得一枚碎片；集齐 5 枚碎片召唤守护冒险岛的大精灵
- 💬 **和泡泡英语对话**：点击地图左下角的泡泡头像，每座**已解锁**的岛都有一场主题英语对话（未解锁岛的对话灰显）。对话大量复现该岛词汇短语：泡泡说英文自动朗读、🔊 可重听、中文翻译点气泡展开/收起；孩子用英文选项回应（选错不扣分，提示重选）。**新增 ask 问答题**：孩子打字回答问句，命中关键词即通过，连续 2 次不通过给出示范答案继续。跟读任务点「✋ 我读过了」手动通过。每场对话**每天首次完成 +2⭐**（计入额外奖励星星），当天重玩无奖励但提示「复习也很棒！」
- 💬 **泡泡自由聊天室**：点击泡泡头像菜单里的「💬 自由聊天」，可以和泡泡用英文/中文自由打字聊天！离线关键词意图引擎识别 15 种话题（问候、学校、动物、食物等），回复中嵌入岛词库单词顺势考拼写；3 轮没聊上，泡泡主动发起单词小挑战。对话历史保留最近 6 轮
- 💬 **泡泡自由聊天室**：点击泡泡头像菜单里的「💬 自由聊天」，可以和泡泡用英文/中文自由打字聊天！离线关键词意图引擎识别 15 种话题（问候、学校、动物、食物等），回复中嵌入岛词库单词顺势考拼写；3 轮没聊上，泡泡主动发起单词小挑战。对话历史保留最近 6 轮
- 🛒 **星星商店**（HUD 🛒 按钮）：星星余额 = 闯关星星 + 对话奖励星星 − 已花费星星，HUD 的 ⭐ 显示的就是可用余额。商品全是装扮：泡泡饰品（🎀🎩🕶️🪄，同时戴 1 个，显示在头像右上角）、宠物跟班（🐰🐱🦊，同时带 1 只，在地图上陪泡泡浮动）、岛屿装饰（🌈⛲🏰，可叠加摆放多个，渲染在世界地图上层不遮门）。购买/装备有音效和提示；清空记录时商店数据一并重置
- 📊 **冒险总览**（HUD 右上角）：总星星、碎片收集、今日需复习数量、每扇门的星级 / 上次闯关 / 下次复习日期；**底部新增「默写薄弱词」板块**，按错误次数排序 top 8，点击可直接跳转对应门的默写训练
- ⚙️ **设置**：声音开关、朗读嗓音选择 + 试听、语速（0.7~1.1x）、答题限时、**默认默写难度（L1/L2/L3）+ 难度自动升级开关**、家长选项（解锁全部岛屿）、清空记录（一并重置默写统计、聊天历史）
- 进度自动保存在浏览器本地（localStorage，键名 `word-adventure-save-v2`；旧版 v1 存档首次打开时自动迁移）。新增存档字段：`spellStats`（默写对错统计）、`dictationMastery`（每门默写最高难度）、`dictationConsecutivePerfect`（每门连续全对次数，用于自动升级）、`freeChatHistory`（最近 6 轮聊天）

## 目录结构

```
word-adventure/
├── index.html            # 游戏入口（双击打开）
├── game.js               # 游戏逻辑
├── style.css             # 画面样式
├── data/
│   ├── words.json        # ★ 词库主文件（人工维护这个）
│   └── words-data.js     # 自动生成，供浏览器加载，勿手改
├── assets/handouts/      # 讲义原图归档（_preview/ 为压缩预览）
└── tools/
    └── build-data.py     # 词库构建脚本
```

## 如何新增讲义

1. 把讲义照片放入 `assets/handouts/`
2. 让 AI 把图片内容提取为词条，追加到 `data/words.json` 的 `units`（新增一个 unit 对象；
   新 unit 的 `entries` 使用新的 `door` 编号，并在顶层 `doors` 数组追加对应的门；
   词条结构见文件顶部 `schema` 说明）
3. 运行 `python3 tools/build-data.py` 重新生成 `words-data.js`
4. （可选）在 `game.js` 的 `ISLAND_META` 数组追加岛屿短名和图标，如
   `{ id: 'u7u8-xxx', short: '冒险岛', icon: '🚀' }`；不追加也能玩，会自动用 unit.title 兜底成岛
5. 刷新浏览器，新岛屿自动出现在世界地图上

## 调试入口（地址栏 hash）

| hash | 作用 |
| --- | --- |
| `#play-N` | 直接进入第 N 扇门闯关 |
| `#match-N` | 直接进入第 N 扇门连连看 |
| `#dictation-<doorId>` | 直接进入该门默写训练营，如 `#dictation-1` |
| `#freechat` | 打开泡泡自由聊天室 |
| `#overview` | 打开冒险总览 |
| `#settings` | 打开设置面板 |
| `#dialogue-test` | 播放健康岛开场白 |
| `#shop` | 打开星星商店 |
| `#chat-<unitId>` | 直接进入该岛英语对话，如 `#chat-u5u6-doctor-challenge` |
